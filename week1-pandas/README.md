## 任务

把 `data/messy_activities.csv` 清洗成 `clean_activities.csv`，**严格按下面 12 条规则执行**。

### 规则（按顺序）

| # | 规则 | 说明 |
|---|---|---|
| 1 | 删掉 `序号` 列 | 无意义 |
| 2 | 所有文本列去掉首尾空格 | 文本列 = `molecule_id` `smiles` `standard_type` `standard_units` `standard_value`（`template.py` 里的 `TEXT_COLS` 已经写好了）。⚠️ 空单元格读进来是 `NaN`，不是空字符串 |
| 3 | 丢弃 `molecule_id` 或 `smiles` 缺失的行 | 没有结构的分子无法建模 |
| 4 | 只保留 `standard_type` 等于 `IC50` 的行 | 大小写不敏感（`ic50` 也算） |
| 5 | 归一化 `standard_units` | 忽略大小写和空格，`µ`/`μ` 都当 `u`。结果只能是 `nM` / `uM` / `mM` |
| 6 | 丢弃 `standard_value` 以 `>` 或 `<` 开头的行 | 删失数据，真值不确定 |
| 7 | 从 `standard_value` 里**提取数字部分** | `"100.0 nM"` → `100.0` |
| 8 | 丢弃无法转成数字的行，以及数值 ≤ 0 的行 | `n.d.`、空、负数、零 |
| 9 | 把数值统一换算成 **nM** | 用归一化后的单位 |
| 10 | 计算 `pIC50 = 9 - log10(值_nM)` | `1 nM` → `pIC50 = 9`；`1000 nM` → `6` |
| 11 | **删除完全重复的行**（所有列都相同） | ⚠️ 必须在聚合**之前**做 |
| 12 | 按 `molecule_id` 聚合 | `pIC50` 取**中位数**，`n_records` 是该分子的记录条数，`smiles` 取第一条（同一分子的 smiles 本来就相同，取哪条都一样） |

### 输出要求

`clean_activities.csv`，**恰好这 4 列**（顺序也要一致）：

| 列名 | 类型 | 含义 |
|---|---|---|
| `molecule_id` | str | 分子编号 |
| `smiles` | str | 分子结构 |
| `pIC50` | float | 该分子所有记录的 pIC50 中位数 |
| `n_records` | int | 该分子有几条有效测定 |

按 `pIC50` **降序**排列。

## 常见坑

**遇到报错先查这份表**：[pandas 调试速查表](../../guides/pandas调试速查表.md)
—— 按"你看到的现象"查，不是从头读。

里面最关键的三条：
- **`astype(str)` 会把缺失值变成字符串 `'nan'`**，过滤不掉（速查表症状 ④）
- `dtypes` 是排查一切问题的第一步（速查表第 0 步"诊断五连"）
- 用 **print 二分法**定位流水线里哪一步出错（速查表最后一节）

| 现象 | 原因 |
|---|---|
| `astype(str)` 之后出现一堆 `'nan'` 字符串 | 用 `.astype("string")`（pandas 的字符串类型，保留缺失）或先 `fillna("")` |
| `str.startswith((">","<"))` 报错 | 加 `na=False` |
| 提取数字时把 `-478.6` 提成了 `478.6` | 正则要加 `^` 锚定，或者先判断负号 |
| 单位归一化漏了 `µM` | 它是希腊字母 mu (U+00B5)，不是英文字母 u |
| 分子数比预期多 | 你可能忘了第 11 步去重 |
| `AttributeError: Can only use .str accessor` | 这列已经不是字符串了（你可能已经转换过），查 `df.dtypes` |
